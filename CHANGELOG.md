# Changelog

All notable changes to this project are documented here. The project follows Semantic Versioning.

## [1.0.0] - 2026-08-17

### Added

- Final post-merge guard for OpenCode's hidden compaction agent.
- Independent persisted compaction effort selection.
- Main and selector-style slash commands.
- Safe fallback to none when state is absent or invalid.
- Atomic state writes with owner-only file permissions.
- Dependency-free test suite and multi-version CI.
- Installation, configuration, contribution, and security documentation.
